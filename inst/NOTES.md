# Sources read

A running record of sources read during merchandiser development, kept so
provenance is auditable rather than remembered. Add an entry with the date
whenever a new source is read in support of a port, coefficient table, scaling
rule, product rule, or documentation claim.

| Date | Source | Notes |
|---|---|---|
| 2026-09-07 | The treevolume package, merged into merchandiser at 0.2.0 | Package standards, workflow structure, and the public C++ header contract were used to create this skeleton. The compiled probe includes `treevolume/kernels.hpp` and evaluates its `demo_paraboloid` diameter entry point. |
| 2026-09-07 | US Forest Service National Volume Estimator Library, <https://github.com/FMSC-Measurements/VolumeLibrary>, pinned commit `38548071d5aa652bb90c7f111f86b427f798a1c9` | Read `numlog.f`, `segmnt.f`, and `scrib.f` for the independent `NUMLOG`, `SEGMNT`, `SCRIB`, and `INTL14` ports. The `NUMLOG` and `SEGMNT` headers credit Jim Brickell, TCFPM R-1, for the logic and WO-TM for implementation. The scaling tables and constants are regenerated by `data-raw/extract_nvel_scaling.R`. |
| 2026-09-09 | US Forest Service Forest Inventory and Analysis `REF_SPECIES.csv`, local official download | Shipped the FIA code, symbol, common-name, and scientific-name aliases used only when the installed treevolume species table lacks text fields. The aliases ship in the species reference table only. |

The pinned NVEL revision matches `merchandiser::nvel_source_revision()` and the
external oracle fixture release used for differential tests.

  does not download or ship FIA tree records.

## Species reference refresh for 0.2.0

Read a local copy of `REF_SPECIES.csv`, the Forest Inventory and Analysis
DataMart export dated 2021-05-28, on 2026-09-10. The file has 2,676 data rows.
Ran `data-raw/species.R` with `FIA_REF_SPECIES` pointing to that file.
Names, symbols, and scientific names were joined by species code. Numerical
properties still come from the pinned source library and were not replaced.
The generator writes the private header under `inst/include/treevolume`,
the retained internal module directory after the merge.
